# UX and accessibility

Practitioner workflow is coherently built around “what is outstanding”: templates, bulk request/chase, item review, timeline, export and practice identity exist. Gaps include one request per link, no scheduled repeat, no multi-entity client portal, passphrase setup, mail setup, hosted account/workspace transitions, and manual handling of failed sends.

Client experience has practice identity, no account, checklist, receipt, phone photo uploads, unavailable/later answers and messaging. A link is bearer access; file preflight is heuristic, not malware or authenticity verification. Slow network, retry and older/less technical users need real-device validation.

Automated site/style checks report contrast pairs above AA (tightest measured 4.68:1) and structural checks across 42 pages. No full WCAG 2.2 AA audit, keyboard-only review, screen-reader test, zoom/reflow review or disabled/older-user test was performed. Do not claim compliance.

Five valuable next checks: fix hosted invitation/login journey; make trial/onboarding honest and one-path; test recovery/passphrase comprehension; run mobile camera/large upload/slow-network retry tests; interview buyers about one-link-per-request and multi-entity fit before building broader portal/scheduler.
